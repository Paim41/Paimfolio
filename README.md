## About

Paimfolio is a personal **portfolio and freelance booking platform** for Paim, a full-stack designer and developer.

Beyond the usual "about me" page, it doubles as a working business front: fixed-price service packages, a booking flow, an admin area, and a contact form — all designed to turn visitors into clients.

> *"Building beautiful, fast web experiences — available for freelance projects."*

---

## Site Flow

```
Landing            →  Hero, availability status, tech stack
    ↓
Selected Work      →  Recent projects, case studies
    ↓
Services & Pricing →  Fixed-price packages, delivery timelines
    ↓
Book This           →  Booking flow for a chosen package
    ↓
About / Contact     →  Personal story, get-in-touch form
```

---

## Features

- **Hero with Video Background** — Motion-driven intro with an availability badge
- **Tech Stack Marquee** — Scrolling showcase of tools and frameworks used
- **Selected Work** — Curated project showcase
- **Services & Pricing** — Fixed-price packages (Landing Page, Full-stack Web App, UI/UX Design) with clear delivery timelines and a "Book this" call to action
- **Booking Flow** — Visitors can book a service package directly
- **Admin Panel** — Private route for managing content and bookings
- **Contact Form** — Direct messaging with a 24-hour response commitment
- **Fully Responsive** — Optimised across desktop and mobile

## Deploying Your Own Version

1. Fork or clone this repository
2. Install dependencies with `npm install`
3. Set up Supabase and Resend environment variables
4. Run locally with `npm run dev`
5. Deploy instantly for free on [Vercel](https://vercel.com/)
